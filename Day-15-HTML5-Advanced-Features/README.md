# Day 15 - HTML5 Advanced Features

## Overview

Day 15 focused on exploring advanced HTML5 features that improve user experience and enable richer web applications. The topics covered include Web Storage for client-side data persistence, HTML5 multimedia elements for embedding audio and video, and MathML for displaying mathematical expressions on web pages.

These features help developers create more interactive, efficient, and standards-compliant websites without relying heavily on external libraries.

---

## Learning Objectives

By the end of this day, I was able to:

- Store and retrieve data using Local Storage and Session Storage.
- Embed and control audio and video using HTML5 multimedia elements.
- Display mathematical expressions using MathML.
- Understand when to use client-side storage.
- Create richer web content using native HTML5 features.

## Key Takeaways

- Local Storage persists data even after closing the browser.
- Session Storage stores data only during the current browser session.
- HTML5 provides built-in audio and video support.
- Multimedia elements eliminate the need for third-party plugins.
- MathML enables mathematical notation directly in HTML documents.
