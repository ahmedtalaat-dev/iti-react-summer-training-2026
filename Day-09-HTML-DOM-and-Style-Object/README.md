# Day 09 - HTML DOM and Style Object

> Learning how to work with HTML DOM properties, methods, attributes, and the Style Object to dynamically manipulate web page content and appearance using JavaScript.

---

## Overview

This day focused on understanding how JavaScript interacts with HTML elements through the **HTML DOM (Document Object Model)** and how to dynamically modify the appearance of elements using the **Style Object**.

The DOM allows JavaScript to:

- Access HTML elements.
- Read and modify content.
- Change attributes.
- Update styles dynamically.
- Create more interactive and responsive web pages.

---

## Learning Objectives

By the end of this day, I learned how to:

- Understand HTML DOM properties and methods.
- Access and manipulate HTML elements.
- Work with element attributes.
- Modify content dynamically.
- Use the Style Object to change CSS properties.
- Add and remove CSS classes.
- Follow best practices when working with the DOM.
