# Day 12 - TypeScript

## Overview

Day 12 focused on learning the fundamentals of **TypeScript**, a strongly typed superset of JavaScript developed by Microsoft. TypeScript adds static typing and modern language features that help developers write safer, more maintainable, and scalable applications.

Throughout this day, I learned how TypeScript improves JavaScript development by introducing data types, interfaces, classes, and modules while still compiling to standard JavaScript.

---

## Learning Objectives

By the end of this day, I was able to:

- Understand what TypeScript is and why it is used.
- Set up and compile TypeScript projects.
- Declare variables with explicit types.
- Work with primitive and custom data types.
- Create typed functions.
- Use interfaces to define object structures.
- Build classes using TypeScript.
- Organize code with modules.

## Key Takeaways

- TypeScript builds on JavaScript by adding static typing.
- Type annotations help detect errors during development.
- Interfaces define object shapes and improve code consistency.
- Classes support object-oriented programming with additional features.
- Modules make large applications easier to organize.
- TypeScript compiles into standard JavaScript that runs in all modern browsers.
