# Task 01 - Rectangle and Square Classes

## Objectives

Practice object-oriented programming in TypeScript using classes, inheritance, constructors, method overriding, and static methods.

### Requirements

#### Rectangle

Create a custom `Rectangle` class that includes:

- A constructor that accepts:
  - Width
  - Height
- A `calcCircumference()` method that returns the rectangle's circumference.
- A static method `whoAmI()` that prints:

```text
I am rectangle
```

#### Square

Create a `Square` class that inherits from `Rectangle`.

The class should:

- Accept only one parameter in its constructor.
- Call the parent constructor using `super()`.
- Set both width and height to the same value.
- Override `calcCircumference()`.
- Override `whoAmI()` to print:

```text
I am square
```

Finally:

- Create objects from both classes.
- Verify that `Square` inherits the members of `Rectangle`.
