# Day 13 - HTML5 Advanced Features

## Overview

Day 13 focused on exploring advanced features introduced in **HTML5**. These features improve the structure, accessibility, graphics capabilities, and user experience of modern web applications.

During this day, I learned how to build semantic web pages using HTML5 structural elements, create scalable vector graphics with SVG, draw dynamic graphics using the Canvas API, and utilize the new form elements and input types introduced in HTML5.

---

## Learning Objectives

By the end of this day, I was able to:

- Understand the purpose of semantic HTML elements.
- Build well-structured and accessible web pages.
- Create graphics using SVG.
- Draw shapes and animations using the Canvas API.
- Use modern HTML5 form elements and validation features.
