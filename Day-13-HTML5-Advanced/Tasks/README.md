# Task 01 - Registration Form with HTML5 Inputs

## Objectives

Create a modern travel registration form using HTML5 form features.

### Requirements

- Add a date picker for selecting the trip date.
- Add a range input for selecting the travel budget.
- Display the selected budget value dynamically.
- Use a `<datalist>` containing at least five travel destinations.
- Validate inputs using:
  - `required`
  - `pattern`

---

# Task 02 - Semantic HTML5 Layout

## Objectives

Build a complete webpage using semantic HTML5 structural elements.

### Requirements

Use the following elements:

- `<header>` for the application title and logo.
- `<nav>` for navigation links.
- `<main>` for the primary page content.
- `<section>` for the trip planning area.
- `<article>` for individual destination cards.
- `<aside>` for travel tips or additional information.
- `<footer>` for copyright and contact details.

---

# Task 03 - Canvas API

## Objectives

Use the HTML5 Canvas API to create an interactive face.

### Requirements

- Draw a sad face when the page loads.
- Change the face to a smiling face when the mouse button is pressed.
- Increase the face width while the mouse is pressed.
- Restore the original sad face and size when the mouse button is released.

---

# Task 04 - Web Storage

## Objectives

Store and retrieve trip information using browser storage.

### Requirements

- Save trip information using `localStorage`.
- Load and display the previously saved trip when the page opens.
- Store temporary user selections using `sessionStorage`.

---

# Task 05 - SVG Graphics

## Objectives

Create an interactive SVG illustration.

### Requirements

- Draw a simple face using SVG circles and ellipses.
- Change the color of each facial feature when hovered.
- Restore the original color when the mouse leaves.
- (Optional) Use an SVG illustration of a human face or body.
- Display a tooltip or floating label showing the organ or facial feature name when hovered.
