# Day 19 - JSX, Reusable Components, State, and Props

## Overview

Day 19 focused on some of the core concepts of React development. I learned how to write user interfaces using **JSX**, build **reusable components**, manage dynamic data with **State**, and share data between components using **Props**.

These concepts are fundamental for creating interactive, maintainable, and scalable React applications.

---

## Learning Objectives

By the end of this day, I was able to:

- Understand what JSX is and why React uses it.
- Create reusable React components.
- Manage component data using State.
- Pass data between components using Props.
- Build modular and interactive React applications.

## Key Takeaways

- JSX makes writing React UI more intuitive.
- Components should be reusable and modular.
- State allows components to manage dynamic data.
- Props enable communication between parent and child components.
