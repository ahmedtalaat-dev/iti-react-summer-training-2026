## Task - Personal Page

### Objective

Create a simple personal page using **React**.

### Requirements

- Build the page using React components.
- Use JSX to structure the user interface.
- Divide the page into reusable components (such as Header, About, Skills, Projects, and Footer).
- Pass data between components using **Props**.
- Use **State** where appropriate to manage dynamic content or user interactions.
- Organize the project following a clean component-based structure.
