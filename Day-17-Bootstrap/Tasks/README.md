## Task - Build a Simple Bootstrap Page

### Objective

Create a simple responsive web page using **Bootstrap**.

### Requirements

- Include Bootstrap using a CDN.
- Build the page layout using the Bootstrap Grid System.
- Use Bootstrap components such as:
  - Navbar
  - Cards
  - Buttons
  - Forms (if applicable)
- Apply Bootstrap utility classes for spacing, colors, and alignment.
- Ensure the page is responsive on different screen sizes.
