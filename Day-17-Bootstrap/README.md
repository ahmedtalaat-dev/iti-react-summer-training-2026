# Day 17 - Bootstrap

## Overview

Day 17 focused on learning **Bootstrap**, the most popular CSS framework for building responsive and mobile-first websites quickly. Bootstrap provides a responsive grid system, pre-built UI components, and utility classes that simplify web development.

Using Bootstrap allows developers to create professional-looking interfaces with less custom CSS while maintaining responsive and consistent designs across different devices.

---

## Learning Objectives

By the end of this day, I was able to:

- Understand what Bootstrap is and why it is used.
- Include Bootstrap in a project using a CDN.
- Build responsive layouts using the Bootstrap Grid System.
- Use common Bootstrap components.
- Apply Bootstrap utility classes for spacing, colors, typography, and alignment.
