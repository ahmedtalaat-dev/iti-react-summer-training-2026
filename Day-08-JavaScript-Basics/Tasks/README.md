# DOM Lab Assignments

## Overview

This lab was completed as part of **Day 08 - JavaScript DOM** during the ITI React Summer Training 2026.

The assignments focused on practicing:

- Form Validation
- DOM Events
- DOM Manipulation
- HTML5 Validation
- Image Gallery
- Timers
- Mouse Events
- CSS Transitions & Opacity
