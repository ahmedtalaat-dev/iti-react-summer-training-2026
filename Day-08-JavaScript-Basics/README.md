# Day 08 - JavaScript DOM

> Learning the fundamentals of the Document Object Model (DOM), including selecting elements, manipulating content, handling events, traversing the DOM tree, and dynamically creating web page elements.

---

## Overview

This day focused on understanding the **Document Object Model (DOM)**, which allows JavaScript to interact with and manipulate HTML documents dynamically.

Through DOM manipulation, JavaScript can:

- Access HTML elements.
- Modify content and styles.
- Respond to user interactions.
- Create and remove elements dynamically.
- Build interactive web applications.

---

## Learning Objectives

By the end of this day, I learned how to:

- Understand the DOM structure.
- Select HTML elements using different methods.
- Modify element content and attributes.
- Handle user events.
- Create and remove DOM elements dynamically.
- Navigate between parent, child, and sibling elements.
- Follow DOM best practices.
