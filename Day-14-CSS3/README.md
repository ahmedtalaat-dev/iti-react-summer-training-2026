# Day 14 - CSS3 Fundamentals

## Overview

Day 14 focused on learning the core features of **CSS3** that are essential for creating responsive and interactive web pages. The topics covered include the CSS Box Model, measurement units, and CSS animations.

These concepts provide the foundation for controlling layout, spacing, sizing, and visual effects in modern web development.

---

## Learning Objectives

By the end of this day, I was able to:

- Understand how the CSS Box Model works.
- Use different CSS measurement units appropriately.
- Create smooth animations using CSS3.
- Build more responsive and visually appealing web pages.

## Key Takeaways

- Every HTML element follows the CSS Box Model.
- Choosing the correct measurement unit improves responsive design.
- Relative units make layouts more flexible.
- CSS animations create interactive user experiences without JavaScript.
- Proper use of CSS3 improves both usability and performance.
