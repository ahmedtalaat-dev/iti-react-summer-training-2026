# Task - Build a Complete Landing Page

## Objective

Design and develop a modern landing page using HTML5 and CSS3.

---

## Requirements

- Create a clean and responsive page layout.
- Apply the CSS Box Model for spacing and element sizing.
- Use appropriate CSS measurement units such as:
  - px
  - %
  - rem
  - em
  - vw
  - vh
- Add CSS animations to improve user interaction.
- Use semantic HTML5 elements where appropriate.
- Organize the page into logical sections such as:
  - Header
  - Hero Section
  - Features
  - About
  - Contact
  - Footer
