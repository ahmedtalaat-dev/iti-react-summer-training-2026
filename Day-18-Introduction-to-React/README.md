# Day 18 - Introduction to React

## Overview

Day 18 introduced the fundamentals of **React**, one of the most popular JavaScript libraries for building user interfaces. Along with React, I learned the role of **Node.js** and **npm** in setting up and managing React projects. I also created my first simple React component to understand the component-based architecture of React applications.

---

## Learning Objectives

By the end of this day, I was able to:

- Understand what React is and why it is used.
- Learn the purpose of Node.js in React development.
- Use npm to manage project dependencies.
- Understand the concept of React components.
- Create a simple functional React component.

## Key Takeaways

- React is a JavaScript library for building user interfaces.
- Node.js provides the runtime environment required for React tooling.
- npm is used to install and manage project dependencies.
- React applications are built using reusable components.
- JSX allows writing HTML-like syntax inside JavaScript.
