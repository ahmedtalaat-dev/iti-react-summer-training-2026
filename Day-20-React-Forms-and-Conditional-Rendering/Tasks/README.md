## Task - Todo List App

### Objective

Develop a simple **Todo List** application using React.

### Requirements

- Create a form to add new tasks.
- Display all tasks in a dynamic list.
- Render tasks using the `map()` method.
- Use React state to manage the list of tasks.
- Handle form submission using controlled components.
- Allow users to remove completed or unwanted tasks.
- Use conditional rendering to display appropriate messages (such as when no tasks are available).
