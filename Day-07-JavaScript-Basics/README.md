# Day 07 - JavaScript Basics

## Overview

This day focused on two important JavaScript topics:

- Regular Expressions (RegEx)
- Browser Object Model (BOM)

These concepts are widely used in modern web development for validating user input and interacting with browser features.

---

## Learning Objectives

By the end of this day, I was able to:

- Understand the purpose of Regular Expressions.
- Create and use RegEx patterns for validation.
- Apply RegEx methods in JavaScript.
- Understand the Browser Object Model.
- Use the Window object and its methods.
- Navigate and interact with browser information using BOM objects.
