# Day 16 Tasks - Responsive Home Page with Flexbox

## Overview

This folder contains the practical assignment completed during **Day 16 - Responsive Design Fundamentals**.

The goal of this assignment was to build a responsive home page using **CSS Flexbox** only, without using **CSS Media Queries**. The layout relies on Flexbox properties to create a flexible design that adapts naturally to different screen sizes.

## Task - Responsive Home Page

### Objective

Design and implement a responsive home page using **Flexbox** without using any media queries.

### Requirements

- Build a complete home page layout.
- Use **Flexbox** for all page sections.
- Do **not** use CSS Media Queries.
- Create a layout that adapts naturally to different screen sizes.
- Use flexible widths and wrapping where appropriate.
- Keep the design clean, organized, and user-friendly.
